# LeafSeamer / Seamer

> **施工中 / Work in progress。** 当前仅建立仓库边界和设计入口，尚无生产可用实现。不要用于实际直播控制。

自动化核心：规则、状态机、排期、能力引用和执行记录。通过公共 API 调用 Controller，不实现厂商设备协议。

总体设计、已确认决策、待落实事项和路线图统一维护于 [LeafSeamer Suite](https://github.com/LeafSeamer/leafseamer-suite)。实施准备分支为 `rebirth`；设计确认不等于业务实现已获启动批准。

旧 NodeCG 实现及历史保留于 [leafseamer-legacy](https://github.com/ikenainanodesu/leafseamer-legacy)。本仓尚未导入旧业务源码；后续复用时逐项记录来源、历史映射和必要许可声明。
